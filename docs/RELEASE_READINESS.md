# Release readiness

Updated: 2026-11-14 · Decision: **Development build ready**. Not yet ready for internal testing.

## Done

- Application ID `com.dev.kidsgames`, minSdk 24, version `1.0.0+1`.
- Offline-first: no network calls, accounts, analytics, ads or third-party SDKs that collect data.
- The main manifest requests no permissions. INTERNET appears only in the debug and profile manifests, which Flutter needs for hot reload.
- Parent-only settings sit behind an adult check and a PIN, which is PBKDF2-hashed in Android secure storage.
- Audio is original and generated in-house (`tool/generate_sounds.py`). 3D models are generated by the repository's Blender scripts.
- CI: analyze, about 50 test cases (including validation of all 104,000 generated levels), Blender asset generation and the Android debug APK build all pass.

## Draft Data safety answers (verify in Play Console)

- Data collected: none. The child's first name, grade, scores, drawings and settings are stored only on the device and never transmitted.
- Data shared: none.
- Encryption in transit: not applicable (no network traffic).
- Data deletion: removed when the app is uninstalled; a parent reset is planned.

# Kids Games — Setup steps

1. Install Flutter stable and Android Studio with Android SDK Platform Tools.
2. Clone this repository.
3. Generate the Android platform folder with the Flutter command in the root README.
4. Run `flutter pub get`.
5. Run `flutter analyze` and `flutter test`.
6. Run on an Android emulator or Android device.
7. Replace starter SVGs with original 3D renders as they are produced.
8. Implement onboarding, child profile and parent gate.
9. Implement the 15 mini-games using reusable game patterns.
10. Add learning worlds, tracing, phonics, math, drawing, stories, music, science and life skills.
11. Add local persistence, progress, rewards, revision and screen-time controls.
12. Test airplane-mode behavior, accessibility, performance and data safety before release.

## Asset production checklist
- App icon: original fox-and-star mark, without text.
- Buddy characters: fox, rabbit, panda and additional unlockable friends.
- World thumbnails: 10 original 3D-rendered scenes.
- Game illustrations: transparent PNG/WebP objects with consistent lighting and camera angle.
- Audio: original or commercially licensed letter sounds, instructions, effects and narration.
- Keep source files and license records for every third-party asset.

The SVG illustrations included now are lightweight starter placeholders, not final 3D production artwork.
